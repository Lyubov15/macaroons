# Лендинг кондитерской

**Macaroons** — промостраница кондитерской с каталогом пирожных, описанием преимуществ и формой оформления заказа. Посетитель может ознакомиться с ассортиментом, выбрать понравившийся десерт и перейти к заполнению контактных данных.

[Открыть сайт](https://lyubov15.github.io/macaroons/)

## Возможности

- Презентационный первый экран с описанием продукта.
- Блок с преимуществами и информацией о приготовлении десертов.
- Каталог макарунов с изображениями и ценами.
- Выбор товара из каталога с автоматическим переносом названия в форму заказа.
- Форма заказа с проверкой обязательных полей.
- Проверка вводимых данных: в поле телефона допускаются цифры, в поле имени — буквы.
- Индикатор загрузки и сообщение об успешной отправке формы.
- Адаптивное меню для мобильных устройств.
- Плавная прокрутка между разделами страницы.

## Технологии

- HTML5 — структура страницы и форма заказа.
- CSS3 — оформление и адаптивная верстка.
- LESS — организация и подготовка стилей.
- JavaScript — интерактивность и обработка формы.
- jQuery — работа с DOM, событиями и AJAX-запросами.
- Gulp — компиляция LESS и отслеживание изменений.
- Grunt — конфигурация задач сборки.
- Google Fonts / локальные шрифты — типографика проекта.

## Запуск проекта

Для просмотра страницы локально:

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Lyubov15/macaroons.git
   ```
2. Перейдите в папку проекта:
   ```bash
   cd macaroons
   ```
3. Установите зависимости:
   ```bash
   npm install
   ```
4. Откройте `index.html` в браузере или запустите Live Server.

Для пересборки LESS-стилей и отслеживания изменений предусмотрены задачи Gulp:
```bash
npx gulp
```

## Структура проекта

- `index.html` — разметка лендинга.
- `index.js` — логика меню, выбора товара и формы заказа.
- `src/styles/` — исходные LESS-файлы.
- `dist/css/` — готовые CSS-стили, подключаемые страницей.
- `assets/images/` — изображения, логотип и иконки.
- `assets/fonts/` — локальные шрифты.
- `gulpfile.js` — задачи Gulp.
- `gruntfile.js` — конфигурация Grunt.

> Форма заказа в проекте демонстрационная. Отправка данных настроена на тестовый endpoint Testologia и не является подключением к реальной системе приема заказов.
